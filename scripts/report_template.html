Pool labels approximate UTF-8 text size. The table below uses exact measured record and byte counts.

Total training tokens

Exact token counts in the training split, excluding validation. Each cell describes one tokenized stream shared by all three model sizes; counts are before dropping the incomplete final batch. Only the 5GB, 10GB, and 20GB pools are tokenized for model training.

One-epoch tokens = floor(train tokens / (context × global batch)) × context × global batch. Context = round(4096 × target tokens/byte ÷ the same pool’s 32K tokens/byte). Both tokenization streams must finish before FLOPs are calculated. Model FLOPs/token comes directly from the pinned EMO model, including attention and the vocabulary-dependent output projection; it excludes recomputation and hardware overhead.

Training and validation BPB are token-averaged CE × that split’s measured tokens/byte ÷ ln(2). These are split-normalized loss estimates, separate from the shared held-out Dolma BPB evaluation. Their observation steps and all run hyperparameters are retained in the downloadable report data.
